Buscar en YouTube

Estás abriendo la página con doble clic. Para que YouTube funcione ábrela desde un servidor local (npx serve o la extensión Live Server de VS Code).

    API key de YouTube
    1. Entra a console.cloud.google.com y crea un proyecto.
    2. Busca YouTube Data API v3 y pulsa Habilitar.
    3. Ve a Credenciales → Crear credenciales → Clave de API.
    4. Pega la clave aquí abajo. Solo se guarda en este navegador.
